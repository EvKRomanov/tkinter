# Лабораторная работа №1: Простая анимация в Tkinter

## Описание проекта
Программа реализует симуляцию анимации «Дождь» с использованием графической библиотеки Tkinter.

### Особенности реализации:
- **Генерация частиц**: на холсте одновременно генерируется массив капель, движущихся вниз.
- **3D-эффект**: реализована иллюзия глубины пространства — дальние капли тоньше и падают медленнее, ближние — крупнее и быстрее.
- **Цикличность**: при выходе за нижнюю границу окна объект удаляется и генерируется заново сверху.
- **Плавность кадров**: обновление сцены происходит через `root.after(16, animate)` (~60 FPS).

## Запуск

python main.py
